# AlgoQuest — Η Ακαδημία των Αλγορίθμων

Εκπαιδευτικό παιχνίδι σε **Java (Swing)** για το αντικείμενο των **Αλγορίθμων**.
Εργασία: ΘΕΜΑ 1Α — Ανάπτυξη εκπαιδευτικού παιχνιδιού (Πανεπιστήμιο Πειραιώς, Τμήμα Πληροφορικής).

## Εκτέλεση

**Από IntelliJ IDEA:** Άνοιξε τον φάκελο ως project και τρέξε την κλάση `com.uni.AlgoQuest.Main`.

**Από γραμμή εντολών (Git Bash):**
```bash
cd ~/IdeaProjects/AlgoQuest
javac -encoding UTF-8 -d out/production/AlgoQuest src/com/uni/AlgoQuest/*.java
java -cp out/production/AlgoQuest com.uni.AlgoQuest.Main
```
> Το `-encoding UTF-8` είναι απαραίτητο επειδή ο κώδικας περιέχει ελληνικά κείμενα.

## Τα τρία mini-games

| Παιχνίδι | Τι διδάσκει | Πώς παίζεται |
|---|---|---|
| **Κουίζ Αλγορίθμων** | Πολυπλοκότητα, ταξινόμηση, αναζήτηση, δομές δεδομένων, γράφοι, αναδρομή, DP/greedy | 10 ερωτήσεις πολλαπλής επιλογής με χρονόμετρο, σερί και βοήθεια 50-50 |
| **Sort Race** | Bubble Sort & αντιστροφές πίνακα | Αντιμεταβολές ΓΕΙΤΟΝΙΚΩΝ στηλών μέχρι την ταξινόμηση, με στόχο το ελάχιστο πλήθος κινήσεων (= αντιστροφές) |
| **Το Κυνήγι του Αριθμού** | Δυαδική αναζήτηση & λογαριθμική πολυπλοκότητα | Εύρεση κρυφού αριθμού με ανατροφοδότηση «μεγαλύτερος/μικρότερος» και οπτικοποίηση του διαστήματος που μικραίνει |

## Κάλυψη των κριτηρίων της εκφώνησης

| Κριτήριο | Πώς υλοποιείται |
|---|---|
| **Ελκυστικότητα** | Μοντέρνο σκούρο UI με custom ζωγραφισμένα κουμπιά/κάρτες/μπάρες, χρώματα ανατροφοδότησης, ηχητικά εφέ (συνθετικοί τόνοι, χωρίς εξωτερικά αρχεία), οπτικοποιήσεις (στήλες ταξινόμησης, διάστημα αναζήτησης) |
| **Διαδραστικότητα** | Κλικ σε στήλες για αντιμεταβολές, προβλέψεις με άμεση απόκριση, χρονόμετρο ανά ερώτηση, hover εφέ, βοήθειες (50-50, υπόδειξη Bubble Sort, «δείξε τη μέση») |
| **Παιχνιδοποιημένες δραστηριότητες** | 3 διαφορετικά mini-games με αποστολές, αστέρια (1–3 ★) ανά παρτίδα, πίνακας βαθμολογιών (top scores) |
| **Ανατροφοδότηση & αμοιβές** | Άμεση εξήγηση σε κάθε απάντηση (σωστή ή λάθος), ανάλυση πόντων (βάση + ταχύτητα + σερί), XP & επίπεδα προφίλ, **παράσημα** («Πρώτα Βήματα», «Σερί ×5», «Αλάνθαστος», «Master Ταξινόμησης», «Λογαριθμικό Μυαλό», «Νικητής Versus»), κερδιζόμενες βοήθειες 50-50, ήχοι επιτυχίας/αποτυχίας |
| **Προσαρμοστικότητα δυσκολίας** | `AdaptiveEngine`: 3 σωστές στη σειρά → ανεβαίνει επίπεδο, 2 λάθη → κατεβαίνει. Το επίπεδο καθορίζει τη δεξαμενή ερωτήσεων, τον διαθέσιμο χρόνο, το μέγεθος του πίνακα στο Sort Race και το εύρος στο Κυνήγι του Αριθμού. Ο παίκτης ενημερώνεται για κάθε προσαρμογή |
| **Συνεργασία / Επικοινωνία / Διαμοιρασμός** (bonus) | **Versus 2 παικτών** στις ίδιες ερωτήσεις (pass-and-play), **κωδικοί πρόκλησης** (π.χ. `AQ-3F9A2`) που αναπαράγουν την ίδια παρτίδα σε άλλον υπολογιστή για σύγκριση σκορ, **κάρτα σκορ** που αντιγράφεται στο πρόχειρο και αποθηκεύεται σε `.txt` για αποστολή, κοινός πίνακας βαθμολογιών |

## Δομή κώδικα (πακέτο `com.uni.AlgoQuest`)

| Αρχείο | Ρόλος |
|---|---|
| `Main.java` | Σημείο εκκίνησης |
| `GameFrame.java` | Κεντρικό παράθυρο, μενού, πλοήγηση, προφίλ/παράσημα, βαθμολογίες |
| `Theme.java` | Χρώματα, γραμματοσειρές, custom styled components |
| `SoundFx.java` | Συνθετικά ηχητικά εφέ |
| `Models.java` | Μοντέλα δεδομένων + αποθήκευση με serialization (`algoquest_data.ser`) |
| `QuestionBank.java` | 24 ερωτήσεις σε 3 επίπεδα δυσκολίας, όλες με εξήγηση |
| `AdaptiveEngine.java` | Μηχανισμός προσαρμοστικής δυσκολίας |
| `QuizPanel.java` | Κουίζ (1 παίκτης ή Versus) |
| `SortRacePanel.java` | Sort Race |
| `BinarySearchPanel.java` | Το Κυνήγι του Αριθμού |
| `ResultsPanel.java` | Αποτελέσματα + διαμοιρασμός κάρτας σκορ |

Τα δεδομένα (προφίλ, XP, παράσημα, βαθμολογίες) αποθηκεύονται αυτόματα στο `algoquest_data.ser`
στον φάκελο εκτέλεσης και διατηρούνται μεταξύ εκτελέσεων.

## Ιδέες ένταξης στην εκπαιδευτική διαδικασία (για το μέρος Β)

- **Πριν τη διάλεξη:** οι φοιτητές παίζουν το Κυνήγι του Αριθμού ως βιωματική εισαγωγή στη δυαδική αναζήτηση πριν διδαχθούν τη θεωρία.
- **Στο εργαστήριο:** τουρνουά Versus ανά ζεύγη· ο διδάσκων μοιράζει έναν κωδικό πρόκλησης ώστε όλη η τάξη να παίξει την ίδια παρτίδα και να συγκριθούν τα σκορ δίκαια.
- **Επανάληψη πριν την εξέταση:** το κουίζ με την προσαρμοστική δυσκολία λειτουργεί ως αυτοαξιολόγηση· οι εξηγήσεις σε κάθε ερώτηση καλύπτουν τα κενά.
- **Formative assessment:** ο πίνακας βαθμολογιών και οι κάρτες σκορ που μοιράζονται οι φοιτητές δίνουν στον διδάσκοντα εικόνα προόδου χωρίς βαθμολογικό άγχος.
